# Como aplicar

1. Extraia este pacote na raiz do repositório `TimeTracker-2026-2`, preservando os caminhos.
2. Confirme que somente arquivos em `FrontEnd/` serão substituídos/adicionados.
3. Execute:

```bash
cd FrontEnd
npm ci
npm test
npm run build
```

4. Revise o diff antes do commit.

Nenhum arquivo do backend faz parte deste pacote.
