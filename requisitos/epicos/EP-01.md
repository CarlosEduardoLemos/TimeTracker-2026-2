# EP-01 — Identificar usuários e associar equipe

## Objetivo

Permitir a identificação e autenticação dos usuários do Time Tracker e organizar os colaboradores associados a cada gestor.

O gestor possui conta própria e acessa o Dashboard por login.

O colaborador é identificado automaticamente pelo Agente Desktop, sem necessidade de criar conta ou realizar login manualmente.

A associação entre colaborador e gestor ocorre por meio de um código de 6 dígitos.

## Requisitos Funcionais

* RF-01, RF-02, RF-03, RF-04, RF-05.

## Regras de Negócio

* RN-01, RN-02.

## Requisitos Não Funcionais

* RNF-03, RNF-04, RNF-05, RNF-12.

## Critérios de Aceite relacionados

* CA-01 — Identificação, acesso e associação.
* CA-09 — Privacidade e segurança (parcial: autenticação e acesso).

## Escopo

Este épico contempla:

* cadastro e login do gestor;
* identificação automática do colaborador;
* registro automático do colaborador quando necessário;
* autenticação automática do Agente Desktop;
* geração de código de associação;
* associação entre colaborador e gestor;
* consulta dos colaboradores associados;
* disponibilização dos colaboradores para utilização nas tasks;
* controle de acesso aos colaboradores.

## User Stories

### US-01 — Acessar o sistema como gestor

**Como** gestor
**Quero** criar minha conta e acessar o Dashboard
**Para** administrar minha equipe.

#### Resultado esperado

O gestor deve conseguir criar uma conta, realizar login e acessar somente os recursos sob sua responsabilidade.

#### Tarefas

* [ ] TASK-01 — Implementar cadastro do gestor.
* [ ] TASK-02 — Implementar login e sessão.
* [ ] TASK-03 — Aplicar permissões do gestor.

---

### US-02 — Identificar o colaborador automaticamente

**Como** colaborador
**Quero** ser identificado automaticamente pelo Agente Desktop
**Para** utilizar o sistema sem criar conta ou realizar login.

#### Resultado esperado

O agente deve identificar o colaborador e sua estação, registrá-lo quando necessário e autenticar-se automaticamente no backend.

#### Tarefas

* [ ] TASK-04 — Identificar colaborador e estação.
* [ ] TASK-05 — Registrar o colaborador quando necessário.
* [ ] TASK-06 — Autenticar o agente automaticamente.

---

### US-03 — Associar colaborador ao gestor

**Como** gestor
**Quero** gerar um código de associação
**Para** adicionar colaboradores à minha equipe.

**Como** colaborador
**Quero** informar esse código no Agente Desktop
**Para** me associar ao gestor.

#### Resultado esperado

O gestor deve gerar um código de 6 dígitos e o colaborador deve utilizá-lo para concluir a associação.

#### Tarefas

* [ ] TASK-07 — Gerar código de associação.
* [ ] TASK-08 — Validar código informado no agente.
* [ ] TASK-09 — Registrar a associação colaborador ↔ gestor.

---

### US-04 — Gerenciar equipe

**Como** gestor
**Quero** visualizar meus colaboradores associados
**Para** utilizá-los nas tasks sob minha responsabilidade.

#### Resultado esperado

O gestor deve visualizar somente os colaboradores associados a ele e utilizá-los nas funcionalidades permitidas.

#### Tarefas

* [ ] TASK-10 — Listar colaboradores associados.
* [ ] TASK-11 — Disponibilizar colaboradores nas tasks.
* [ ] TASK-12 — Validar permissões de acesso.

## Definição de concluído

O épico é considerado concluído quando:

* [ ] gestor puder criar conta e realizar login;
* [ ] colaborador for identificado e registrado automaticamente;
* [ ] agente puder se autenticar automaticamente;
* [ ] associação por código estiver funcionando;
* [ ] gestor visualizar somente seus colaboradores;
* [ ] colaboradores associados estiverem disponíveis nas tasks;
* [ ] o CA-01 e as partes aplicáveis do CA-09 estiverem atendidos;
* [ ] testes e documentação estiverem atualizados.
