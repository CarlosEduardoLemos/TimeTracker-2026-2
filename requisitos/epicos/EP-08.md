# EP-08 — Dashboard analítico

## Objetivo

Este épico tem como objetivo permitir que o gestor visualize de forma consolidada as informações dos colaboradores associados.

O Dashboard deve apresentar indicadores e visualizações que facilitem o acompanhamento das tasks, atividades registradas e estados dos colaboradores.

## Requisitos Funcionais

* RF-27.

## Regras de Negócio

* RN-19.

## Requisitos Não Funcionais

* RNF-05, RNF-12.

## Critérios de Aceite relacionados

* CA-10 — Dashboard analítico.

## Escopo

Este épico contempla:

* exibir a quantidade de colaboradores Online e Offline;
* exibir a quantidade de tasks ativas;
* apresentar o tempo total Ativo e Inativo;
* apresentar o tempo registrado por task;
* apresentar possíveis horas extras;
* apresentar o estado dos colaboradores;
* apresentar a sequência das atividades registradas;
* disponibilizar uma Activity Timeline;
* identificar períodos de utilização das aplicações;
* identificar períodos de inatividade;
* permitir filtros por período;
* permitir filtros por colaborador;
* permitir filtros por task;
* atualizar os indicadores conforme os filtros selecionados;
* apresentar somente dados dos colaboradores associados ao gestor;
* não utilizar rankings ou métricas de produtividade.

## User Stories

### US-01 — Visualizar resumo da equipe

**Como** gestor
**Quero** visualizar um resumo das atividades da minha equipe
**Para** que eu possa acompanhar o estado geral dos colaboradores.

#### Resultado esperado

O Dashboard deve apresentar informações consolidadas da equipe, incluindo:

* colaboradores Online;
* colaboradores Offline;
* tasks ativas;
* tempo total Ativo;
* tempo total Inativo.

#### Tarefas

* [ ] TASK-01 — Buscar os colaboradores associados ao gestor.
* [ ] TASK-02 — Identificar colaboradores Online e Offline.
* [ ] TASK-03 — Identificar a quantidade de tasks ativas.
* [ ] TASK-04 — Calcular o tempo total Ativo.
* [ ] TASK-05 — Calcular o tempo total Inativo.
* [ ] TASK-06 — Criar os indicadores do Dashboard.

### US-02 — Visualizar tempo por task

**Como** gestor
**Quero** visualizar o tempo registrado em cada task
**Para** que eu possa acompanhar o período dedicado às atividades.

#### Resultado esperado

O Dashboard deve apresentar o tempo registrado por task com base nos registros existentes.

As informações devem respeitar os filtros e as permissões do gestor.

#### Tarefas

* [ ] TASK-07 — Buscar os registros relacionados às tasks.
* [ ] TASK-08 — Calcular o tempo registrado por task.
* [ ] TASK-09 — Associar os valores às respectivas tasks.
* [ ] TASK-10 — Criar visualização do tempo por task.

### US-03 — Visualizar Activity Timeline

**Como** gestor
**Quero** visualizar a sequência das atividades registradas
**Para** que eu possa entender como as atividades ocorreram durante o período selecionado.

#### Resultado esperado

O Dashboard deve apresentar uma **Activity Timeline** contendo a sequência das atividades registradas.

A timeline deve permitir identificar:

* aplicação utilizada;
* período de utilização;
* períodos Ativos;
* períodos Inativos;
* task relacionada;
* atividades dentro ou fora do escopo da task.

#### Tarefas

* [ ] TASK-11 — Buscar os registros de atividade.
* [ ] TASK-12 — Ordenar os registros cronologicamente.
* [ ] TASK-13 — Identificar aplicação e período de utilização.
* [ ] TASK-14 — Identificar períodos Ativos e Inativos.
* [ ] TASK-15 — Associar as atividades às respectivas tasks.
* [ ] TASK-16 — Identificar atividades dentro ou fora do escopo.
* [ ] TASK-17 — Criar a Activity Timeline.

### US-04 — Filtrar informações do Dashboard

**Como** gestor
**Quero** filtrar as informações apresentadas
**Para** que eu possa analisar somente os dados relevantes para minha consulta.

#### Resultado esperado

O Dashboard deve permitir aplicar filtros por:

* período;
* colaborador;
* task.

Quando um filtro for alterado, os indicadores e visualizações relacionados devem ser atualizados.

#### Tarefas

* [ ] TASK-18 — Criar filtro por período.
* [ ] TASK-19 — Criar filtro por colaborador.
* [ ] TASK-20 — Criar filtro por task.
* [ ] TASK-21 — Aplicar os filtros aos registros.
* [ ] TASK-22 — Atualizar os indicadores após alteração dos filtros.
* [ ] TASK-23 — Atualizar a Activity Timeline conforme os filtros.

### US-05 — Visualizar possíveis horas extras

**Como** gestor
**Quero** visualizar possíveis períodos de hora extra
**Para** que eu possa identificar atividades realizadas após a jornada prevista.

#### Resultado esperado

O Dashboard deve apresentar como indicação os períodos identificados pelo sistema como **possível hora extra**.

A informação não deve representar automaticamente uma confirmação de hora extra.

#### Tarefas

* [ ] TASK-24 — Buscar os períodos identificados como possível hora extra.
* [ ] TASK-25 — Associar os períodos aos colaboradores.
* [ ] TASK-26 — Apresentar a indicação no Dashboard.

## Definição de concluído

O épico é considerado concluído quando:

* [ ] o gestor visualizar colaboradores Online e Offline;
* [ ] o gestor visualizar a quantidade de tasks ativas;
* [ ] os tempos Ativo e Inativo forem apresentados;
* [ ] o tempo por task estiver disponível;
* [ ] a Activity Timeline apresentar a sequência das atividades;
* [ ] atividades dentro e fora do escopo puderem ser identificadas;
* [ ] possíveis horas extras forem apresentadas como indicação;
* [ ] os filtros por período, colaborador e task funcionarem;
* [ ] os indicadores forem atualizados conforme os filtros;
* [ ] somente dados permitidos ao gestor forem apresentados;
* [ ] não forem utilizados rankings ou métricas de produtividade;
* [ ] o CA-10 estiver atendido;
* [ ] os testes necessários forem executados;
* [ ] a documentação relacionada estiver atualizada.
