# EP-06 — Consultar histórico do colaborador

## Objetivo

Este épico tem como objetivo permitir que o colaborador consulte um histórico das informações que foram efetivamente enviadas ao sistema.

O histórico deve ser acessado através da **System Tray**, apresentado em formato **TXT** e formado pelos registros locais marcados como sincronizados.

## Requisitos Funcionais

* RF-26.

## Regras de Negócio

* RN-17.

## Requisitos Não Funcionais

* RNF-05, RNF-07, RNF-12.

## Critérios de Aceite relacionados

* CA-08 — Histórico do colaborador.

## Escopo

Este épico contempla:

* disponibilizar o histórico através da System Tray;
* apresentar o histórico em formato TXT;
* exibir somente registros locais marcados como sincronizados;
* apresentar somente informações pertencentes ao próprio colaborador;
* organizar os registros de forma simples e compreensível;
* permitir que o colaborador consulte o que foi enviado pelo agente.

## User Stories

### US-01 — Acessar histórico pela System Tray

**Como** colaborador
**Quero** acessar meu histórico através da System Tray
**Para** que eu possa consultar as informações enviadas pelo agente.

#### Resultado esperado

A System Tray deve possuir uma opção que permita ao colaborador acessar seu histórico.

O histórico deve apresentar somente registros pertencentes ao próprio colaborador.

#### Tarefas

* [ ] TASK-01 — Criar opção de histórico na System Tray.
* [ ] TASK-02 — Identificar o colaborador registrado no agente.
* [ ] TASK-03 — Buscar os registros disponíveis para consulta.
* [ ] TASK-04 — Garantir que somente registros do próprio colaborador sejam apresentados.
* [ ] TASK-05 — Abrir a visualização do histórico.

### US-02 — Visualizar registros enviados

**Como** colaborador
**Quero** visualizar somente os registros que foram enviados ao sistema
**Para** que eu saiba quais informações foram efetivamente transmitidas.

#### Resultado esperado

O histórico deve apresentar somente registros locais marcados como sincronizados após a confirmação do backend.

Registros que ainda estejam pendentes de sincronização não devem ser apresentados como enviados.

#### Tarefas

* [ ] TASK-06 — Identificar registros locais marcados como sincronizados.
* [ ] TASK-07 — Diferenciar registros enviados de registros pendentes.
* [ ] TASK-08 — Exibir somente registros enviados.
* [ ] TASK-09 — Garantir que registros pendentes não sejam apresentados como enviados.

### US-03 — Apresentar histórico em TXT

**Como** colaborador
**Quero** visualizar meu histórico em um formato simples
**Para** que eu possa compreender facilmente as informações registradas.

#### Resultado esperado

O histórico deve ser apresentado em formato **TXT**, contendo as informações disponíveis dos registros enviados ao sistema.

A apresentação deve ser simples e legível.

#### Tarefas

* [ ] TASK-10 — Definir a estrutura do histórico TXT.
* [ ] TASK-11 — Converter os registros para o formato definido.
* [ ] TASK-12 — Organizar os registros de forma legível.
* [ ] TASK-13 — Exibir o conteúdo ao colaborador.

## Definição de concluído

O épico é considerado concluído quando:

* [ ] o histórico puder ser acessado pela System Tray;
* [ ] somente registros do próprio colaborador forem apresentados;
* [ ] somente registros locais marcados como sincronizados forem exibidos;
* [ ] registros pendentes não forem apresentados como enviados;
* [ ] o histórico for apresentado em formato TXT;
* [ ] as informações forem apresentadas de forma simples e compreensível;
* [ ] o CA-08 estiver atendido;
* [ ] os testes necessários forem executados;
* [ ] a documentação relacionada estiver atualizada.
