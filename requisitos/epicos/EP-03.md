# EP-03 — Configurar jornada e controlar a execução das tasks

## Objetivo

Este épico tem como objetivo permitir que o gestor configure as condições de trabalho e que o colaborador inicie, acompanhe, encerre ou troque suas tasks.

O sistema deve disponibilizar ao Agente Desktop a jornada de trabalho e o limite de inatividade, apresentar as condições do monitoramento e manter visíveis os estados relacionados à execução.

## Requisitos Funcionais

* RF-08, RF-09, RF-10, RF-15, RF-16, RF-17, RF-20, RF-21.

## Regras de Negócio

* RN-05, RN-06, RN-11, RN-13.

## Requisitos Não Funcionais

* RNF-05, RNF-07, RNF-12.

## Critérios de Aceite relacionados

* CA-02 — Tasks e início do monitoramento.
* CA-04 — Estado e execução da task.
* CA-06 — Jornada e inatividade (parcial: configuração).

## Escopo

Este épico contempla:

* configurar a jornada de trabalho do colaborador;
* configurar o limite de inatividade;
* disponibilizar essas configurações ao Agente Desktop;
* selecionar uma task atribuída;
* apresentar as condições de monitoramento;
* solicitar a confirmação de ciência do colaborador;
* iniciar o monitoramento;
* apresentar o estado Ativo/Inativo produzido pelo monitoramento;
* identificar e apresentar o estado Online/Offline;
* permitir ao gestor acompanhar o estado Online/Offline dos colaboradores associados;
* impedir duas tasks ativas simultaneamente;
* encerrar ou trocar uma task ativa.

## User Stories

### US-01 — Configurar jornada e inatividade

**Como** gestor

**Quero** configurar a jornada e o limite de inatividade do colaborador

**Para** que o sistema conheça as condições utilizadas durante suas atividades.

#### Resultado esperado

O Dashboard deve permitir configurar:

* dias de trabalho;
* horário de entrada;
* horário de saída;
* intervalo;
* carga horária;
* limite de inatividade.

Essas configurações devem ficar disponíveis para utilização durante o monitoramento.

#### Tarefas

* [ ] TASK-01 — Criar e salvar a configuração da jornada.
* [ ] TASK-02 — Criar e salvar a configuração do limite de inatividade.
* [ ] TASK-03 — Validar as configurações informadas.
* [ ] TASK-04 — Disponibilizar as configurações para o Agente Desktop.

### US-02 — Iniciar task

**Como** colaborador

**Quero** iniciar uma task atribuída a mim

**Para** que eu possa começar minha atividade e seu respectivo monitoramento.

#### Resultado esperado

Ao selecionar uma task, o colaborador deve visualizar:

* aplicações ou serviços relacionados;
* informações que serão registradas;
* utilização de mouse e teclado para identificação de atividade/inatividade;
* condições relacionadas ao monitoramento.

O monitoramento somente deve começar após a confirmação de ciência do colaborador.

#### Tarefas

* [ ] TASK-05 — Permitir selecionar uma task atribuída.
* [ ] TASK-06 — Apresentar as condições de monitoramento.
* [ ] TASK-07 — Solicitar e registrar a confirmação de ciência.
* [ ] TASK-08 — Iniciar a task e seu monitoramento.

### US-03 — Controlar estado da execução

**Como** colaborador

**Quero** visualizar o estado da task em execução

**Para** que eu saiba quando e como o monitoramento está sendo realizado.

#### Resultado esperado

Enquanto existir uma task ativa, o Agente Desktop deve apresentar:

* task ativa;
* aplicações ou serviços relacionados;
* estado Online/Offline;
* estado Ativo/Inativo.

O colaborador deve ser considerado **Online** enquanto o Agente Desktop estiver autenticado e conectado ao sistema.

O estado **Ativo/Inativo** deve ser apresentado conforme determinado pelo monitoramento.

O Dashboard deve permitir ao gestor visualizar o estado Online/Offline dos colaboradores associados.

#### Tarefas

* [ ] TASK-09 — Exibir a task ativa e suas informações.
* [ ] TASK-10 — Determinar o estado Online/Offline pela conexão autenticada do agente.
* [ ] TASK-11 — Exibir o estado Ativo/Inativo produzido pelo monitoramento.
* [ ] TASK-12 — Atualizar os estados durante a execução.
* [ ] TASK-13 — Exibir ao gestor o estado Online/Offline dos colaboradores associados.

### US-04 — Encerrar ou trocar task

**Como** colaborador

**Quero** encerrar ou trocar minha task ativa

**Para** que o monitoramento acompanhe corretamente a atividade que estou realizando.

#### Resultado esperado

Ao encerrar uma task, o sistema deve finalizar seu monitoramento e registrar o encerramento.

O colaborador não deve possuir duas tasks ativas simultaneamente.

Ao trocar de task, a execução anterior deve ser finalizada antes do início da próxima.

#### Tarefas

* [ ] TASK-14 — Encerrar a task e seu monitoramento.
* [ ] TASK-15 — Registrar o encerramento da execução.
* [ ] TASK-16 — Impedir duas tasks ativas simultaneamente.
* [ ] TASK-17 — Finalizar a task atual antes de iniciar uma nova.

## Definição de concluído

O épico é considerado concluído quando:

* [ ] o gestor puder configurar jornada e limite de inatividade;
* [ ] as configurações estiverem disponíveis para o Agente Desktop;
* [ ] o colaborador puder selecionar e iniciar uma task atribuída;
* [ ] as condições de monitoramento forem apresentadas antes do início;
* [ ] o monitoramento começar somente após a confirmação do colaborador;
* [ ] os estados Ativo/Inativo e Online/Offline forem apresentados corretamente;
* [ ] o gestor puder visualizar o estado Online/Offline dos colaboradores associados;
* [ ] somente uma task puder permanecer ativa por vez;
* [ ] o colaborador puder encerrar ou trocar a task ativa;
* [ ] o monitoramento for encerrado junto com a task;
* [ ] as partes aplicáveis dos critérios de aceite relacionados forem atendidas;
* [ ] os testes necessários forem executados;
* [ ] a documentação relacionada estiver atualizada.
