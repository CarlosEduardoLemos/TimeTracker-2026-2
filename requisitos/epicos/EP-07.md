# EP-07 — Consultar relatórios e exportar dados

## Objetivo

Este épico tem como objetivo permitir a consulta dos registros produzidos pelo sistema e a geração de relatórios sobre as atividades dos colaboradores.

O sistema deve identificar possíveis períodos de hora extra, permitir ao gestor consultar informações dos colaboradores associados e exportar os dados disponíveis em **CSV ou PDF**.

## Requisitos Funcionais

* RF-22, RF-23, RF-24, RF-25.

## Regras de Negócio

* RN-14, RN-15, RN-16.

## Requisitos Não Funcionais

* RNF-05, RNF-12.

## Critérios de Aceite relacionados

* CA-06 — Jornada e inatividade (parcial: possível hora extra).
* CA-07 — Consulta, relatórios e exportação.

## Escopo

Este épico contempla:

* permitir ao colaborador consultar seus próprios registros;
* permitir ao gestor consultar registros dos colaboradores associados;
* consultar informações relacionadas às tasks;
* consultar tempo registrado por task;
* consultar aplicações ou serviços utilizados;
* consultar períodos ativos e inativos;
* consultar informações da jornada;
* identificar atividades realizadas após o término previsto da jornada;
* apresentar possíveis horas extras como indicação;
* aplicar as regras de acesso aos dados;
* exportar relatórios em CSV;
* exportar relatórios em PDF.

## User Stories

### US-01 — Consultar registros do colaborador

**Como** colaborador
**Quero** consultar meu próprios histórico TXT
**Para** que eu possa visualizar as informações registradas durante minhas atividades.

#### Resultado esperado

O colaborador deve conseguir consultar somente os registros vinculados à sua identificação no sistema.

Registros de outros colaboradores não devem estar disponíveis.

#### Tarefas

* [ ] TASK-01 — Identificar o colaborador registrado no agente.
* [ ] TASK-02 — Buscar os registros pertencentes ao colaborador.
* [ ] TASK-03 — Exibir os registros disponíveis.
* [ ] TASK-04 — Garantir que registros de outros colaboradores não sejam acessíveis.

### US-02 — Consultar relatórios dos colaboradores

**Como** gestor
**Quero** consultar relatórios dos colaboradores associados
**Para** que eu possa acompanhar as informações registradas pelo sistema.

#### Resultado esperado

O gestor deve conseguir consultar relatórios contendo informações dos colaboradores associados à sua conta.

Os relatórios podem apresentar:

* tasks;
* tempo por task;
* aplicações ou serviços utilizados;
* atividade/inatividade;
* jornada;
* possíveis horas extras.

#### Tarefas

* [ ] TASK-05 — Buscar os colaboradores associados ao gestor.
* [ ] TASK-06 — Buscar os registros disponíveis.
* [ ] TASK-07 — Gerar informações relacionadas às tasks.
* [ ] TASK-08 — Apresentar o tempo registrado por task.
* [ ] TASK-09 — Apresentar os períodos de atividade e inatividade.
* [ ] TASK-10 — Apresentar informações da jornada.
* [ ] TASK-11 — Comparar os períodos de task ativa com a jornada configurada.
* [ ] TASK-12 — Identificar períodos como possível hora extra.
* [ ] TASK-13 — Apresentar possíveis horas extras como indicação.
* [ ] TASK-14 — Garantir que somente dados permitidos ao gestor sejam apresentados.

### US-03 — Exportar relatório

**Como** gestor
**Quero** exportar as informações dos relatórios
**Para** que eu possa utilizar os dados fora do sistema.

#### Resultado esperado

A área de relatórios deve possuir uma opção de exportação.

O gestor deve poder escolher entre os formatos:

* CSV;
* PDF.

O arquivo exportado deve respeitar os dados atualmente disponíveis para consulta.

#### Tarefas

* [ ] TASK-15 — Criar opção de exportação.
* [ ] TASK-16 — Permitir selecionar o formato CSV.
* [ ] TASK-17 — Permitir selecionar o formato PDF.
* [ ] TASK-18 — Obter os dados do relatório.
* [ ] TASK-19 — Gerar arquivo CSV.
* [ ] TASK-20 — Gerar arquivo PDF.
* [ ] TASK-21 — Disponibilizar o arquivo gerado.

## Definição de concluído

O épico é considerado concluído quando:

* [ ] o colaborador puder consultar seus próprios registros;
* [ ] o colaborador não puder acessar registros de outros usuários;
* [ ] o gestor puder consultar dados dos colaboradores associados;
* [ ] o gestor não puder consultar colaboradores fora de sua responsabilidade;
* [ ] os relatórios apresentarem as informações previstas;
* [ ] atividades após a jornada forem identificadas como possível hora extra;
* [ ] os relatórios puderem ser exportados em CSV;
* [ ] os relatórios puderem ser exportados em PDF;
* [ ] as regras de acesso aos dados forem respeitadas;
* [ ] os critérios aplicáveis do CA-06 e do CA-07 estiverem atendidos;
* [ ] os testes necessários forem executados;
* [ ] a documentação relacionada estiver atualizada.
